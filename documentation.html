Introduction

App Stats permet d'importer des fichiers Excel (.xlsx), de configurer vos colonnes, de filtrer les données et de produire des statistiques mensuelles, graphiques et rapports PDF.

Cette page s'ouvre dans un nouvel onglet pour que vous puissiez consulter l'aide tout en travaillant dans l'application.

Documentation mise à jour le 29/07/2026 — filtre global (activation par pile), mise en page PDF, rapport détaillé filtre courant, presets complets (globalFilter, layout, filterPayload), couleur accent #235da9.

Pour qui ? Les sections « Guide du débutant » et les exemples conviennent aux nouveaux utilisateurs. Les sections détaillées sur les calculs, presets et graphiques s'adressent aux utilisateurs avancés.

Guide du débutant

Suivez ces étapes pour obtenir votre première statistique mensuelle en quelques minutes.

  1. Importer un fichier — Menu ☰ → Importer un fichier .xlsx. Choisissez la ligne d'en-tête, sélectionnez les colonnes et validez.
  2. Configurer les dates — Si une colonne contient des dates, ouvrez Configurer les colonnes et définissez le formateur « Date » avec le format source (liste déroulante : DD/MM/YYYY, DD/MM/YY, avec ou sans heure). Les dates à un chiffre (ex. 5/2/26) sont normalisées automatiquement.
  3. Filtre mensuel — Onglet Filtre mensuel : choisissez la colonne date de référence, créez une pile (+ Nouvelle pile) avec un filtre (ex. texte « contient »).
  4. Voir les résultats — Onglet Valeurs : le tableau affiche le nombre de lignes par pile et par mois (année courante par défaut). Cliquez une cellule pour voir le détail.
  5. Graphique — Onglet Graphiques : sélectionnez les piles (case V/G cochée), réglez la plage, puis Actualiser le graphique.
  6. Exporter — Exporter rapport PDF (en-tête) inclut le tableau Valeurs et tous vos sous-onglets graphiques. Pour un flux guidé : menu ☰ → Rapport rapide.
Exemple concret Vous avez un fichier de tickets support avec une colonne « Statut » et une colonne « Date de clôture ».
1. Formatez « Date de clôture » en date.
2. Créez une pile « Tickets fermés » avec filtre texte : Statut contient « Fermé ».
3. Dans Valeurs, vous verrez combien de tickets fermés existent par mois.

Presets d'import

Dans la fenêtre d'import, la section Presets d'import permet de mémoriser la ligne d'en-tête, les colonnes cochées, les formateurs (dont le format source date) et les filtres du tableau actif. Enregistrez, rechargez ou exportez en JSON. La sélection d'un preset applique immédiatement colonnes et formateurs dans la fenêtre.

Option Date additive : ajoute une colonne date fixe (plus ancienne date du fichier) utile quand le fichier n'a pas de colonne date exploitable.

Les presets sont aussi accessibles via le menu ☰ → Presets.

Colonnes et formatage

Via Configurer les colonnes, vous pouvez renommer les colonnes et appliquer un formateur :

  • Date — conversion avec format source et affichage personnalisé.
  • Nombre — normalisation pour filtres numériques et calculs.
  • Majuscules — uniformisation du texte.

Formats de date à l'import

Lors de l'import ou dans Configurer les colonnes, le format source est choisi dans une liste :

Format sourceExemple
DD/MM/YYYY05/02/2026
DD/MM/YY01/01/26 → interprété comme 01/01/2026
DD/MM/YYYY HH:mm05/02/2026 14:30
DD/MM/YY HH:mm5/2/26 9:05 → 05/02/2026 09:05

Normalisation automatique : si le jour ou le mois n'a qu'un chiffre, un zéro est ajouté devant ; si l'année n'a que deux chiffres, elle est complétée en 20xx.

Un mauvais format de date empêche le regroupement mensuel : vérifiez l'onglet Information si les dates semblent incorrectes.

Barre d'en-tête

La barre d'en-tête est compacte. Les actions principales sont regroupées dans le menu burger (☰) à gauche du titre :

  • Importer un fichier .xlsx — ouvre l'assistant d'import.
  • Presets — ouvre la fenêtre d'import/export de presets (global ou par section).
  • Rapport rapide — assistant guidé : fichier XLSX + preset global + période PDF (voir Rapport rapide).
  • Documentation — ouvre cette page d'aide dans un nouvel onglet.
  • Thème clair / Thème sombre — bascule entre thèmes (mémorisé dans le navigateur).

À droite de l'en-tête :

  • Exporter rapport PDF — tableau Valeurs + tous les graphiques configurés (plage de l'onglet Valeurs).

Les onglets de tableaux (noms des jeux de données importés) se trouvent sous le titre, à côté du menu.

Données

Affiche le tableau brut importé, avec défilement et recherche dans les lignes. Les colonnes sont élargies pour une meilleure lisibilité ; en-têtes alignés avec le corps du tableau.

Information

Résumé du tableau : nombre de lignes/colonnes, types détectés, plages de dates et statistiques numériques.

Filtre global

Les piles du filtre global s'appliquent en amont sur les données importées, avant le filtre courant, le filtre mensuel, Valeurs et Graphiques.

  • Chaque pile possède une case Actif : seules les piles activées filtrent les données.
  • Il n'y a pas de case générale d'activation du filtre global.
  • Un bandeau affiche le nombre de lignes restantes après application des piles globales actives.
  • Mêmes types de filtres que le filtre courant (texte, date, nombre, surfiltre sur pile…).
  • Pas de tableau « Résultat après filtrage » dans cette vue.
Exemple Pile globale « Données valides » (exclure lignes test) → tous les comptages filtre courant/mensuel ne portent que sur les lignes retenues.

Filtre courant

Les piles de filtres combinent plusieurs conditions pour isoler des lignes en temps réel. Contrairement au filtre mensuel, les comptages ne sont pas répartis par mois : vous voyez le résultat global et pouvez y ajouter des calculs, compteurs et analyses de dates comme dans le filtre mensuel.

Types de filtres

  • Texte (contient, commence par, finit par)
  • Valeur exacte (liste multi-sélection)
  • Date (avant, après, période — avec option Fin : date actuelle pour une plage)
  • Nombre (comparaisons et plages)
  • Vide / Non vide
  • Surfiltre — filtrer à partir des résultats d'une autre pile ou d'un calcul (voir ci-dessous)

Connecteurs

ET, OU, AVEC, SANS lient chaque filtre au précédent.

Actions utiles

  • Sidebar — liste des piles et calculs à gauche (sidebar élargie) ; l'élément sélectionné s'édite à droite.
  • V/G — case à cocher sur les piles pour les afficher ou les masquer dans Valeurs et Graphiques.
  • ↑ ↓ — réordonner piles et calculs dans la sidebar.
  • ⧉ / × — dupliquer ou supprimer la pile ou le calcul sélectionné.
  • Importer preset filtre (JSON) — charge un fichier preset exporté.
  • Presets filtres — historique local avec versions.

Sidebar piles et calculs

La sidebar liste toutes les piles puis les calculs, compteurs et analyses. Cliquez un élément pour l'éditer. Le panneau principal (à droite) affiche uniquement l'élément sélectionné ; seule cette zone défile si le contenu est long — la sidebar reste fixe.

  • Chaque pile affiche son comptage de lignes (nombre de lignes correspondantes).
  • Boutons de création dans l'en-tête : + Nouvelle pile, + Calcul, + Compteur, + Analyse dates.
  • Bordure colorée à gauche de chaque entrée (voir Couleurs).

Calculs, compteurs et analyses (filtre courant)

Les mêmes types de calcul que dans le filtre mensuel, mais avec une valeur unique (pas par mois) :

  • Calcul — formule entre piles ou autres calculs (addition, soustraction, ratio…).
  • Compteur — somme numérique, somme de caractères ou occurrences sur les lignes d'une pile (ou d'un calcul source).
  • Analyse dates — moyenne, min, max ou plage de durées en jours entre deux colonnes date ; la colonne de fin peut être Date actuelle.

Comme en filtre mensuel, un compteur ou une analyse peut prendre comme source une pile ou un calcul précédent dans la sidebar.

Résultat après filtrage et export XLSX

Sous les filtres d'une pile ou d'un calcul/compteur/analyse, la section Résultat après filtrage affiche un aperçu des lignes retenues (ou la valeur calculée). Le bouton Exporter XLSX télécharge les lignes filtrées (colonnes du tableau).

Rapport détaillé PDF

Bouton Générer un détaillé (à côté de Exporter XLSX) ouvre une modale :

  • Titre et description du rapport
  • Couleur d'accent (défaut : bleu #235da9, ou couleur de l'onglet Mise en page)
  • Sélection des piles et calculs à inclure, avec réordonnancement ↑ ↓
  • Tout sélectionner / tout désélectionner
  • Choix des colonnes à afficher dans les tableaux de détail

Le PDF généré contient :

  1. Page 1 — tableau récapitulatif (élément, type, résultat, numéro de page)
  2. Pages suivantes — une section par élément avec tableau détaillé des lignes filtrées

Surfiltre

Type de filtre Surfiltre (pile ou calcul source) : restreint les résultats aux lignes déjà retenues par une autre pile ou par un calcul/compteur/analyse existant, puis enchaînez d'autres filtres pour affiner par étapes.

Exemple surfiltre Pile A « Tous les clos » → Calcul B « Montant total » → Pile C avec surfiltre sur B + filtre texte « urgent » = tickets urgents parmi ceux comptés dans B.

Filtre mensuel

Comme le filtre courant, mais les comptages sont répartis par mois selon la colonne date choisie en haut de la vue.

Les filtres date peuvent être relatifs au mois affiché (début, fin, pendant le mois).

Sidebar piles et calculs

La sidebar liste toutes les piles et, en dessous, les calculs, compteurs et analyses dates. Cliquez un élément pour l'éditer dans le panneau principal. Les boutons de création sont dans l'en-tête de la vue :

  • + Nouvelle pile — pile de filtres mensuels
  • + Calcul — formule entre piles ou calculs
  • + Compteur — agrégation sur une pile filtrée
  • + Analyse dates — durées entre deux colonnes date

Case V/G sur les piles : contrôle la visibilité dans Valeurs et Graphiques (les calculs y apparaissent toujours). Utilisez ↑ ↓ pour réordonner piles et calculs librement dans la liste. Boutons ⧉ (dupliquer) et × (supprimer) sur chaque entrée.

Calculs avancés

Calcul formule (+ Calcul)

Combine des piles ou d'autres calculs : addition, soustraction, multiplication, division, ratio, etc.

Compteur (+ Compteur)

Sur le résultat d'une pile filtrée ou d'un calcul précédent, pour chaque mois :

  • Somme d'une colonne numérique
  • Somme du nombre de caractères d'une colonne texte
  • Nombre d'occurrences d'un caractère choisi
Exemple compteur Pile « Commandes validées » + compteur en mode « Somme numérique » sur la colonne « Montant » → total des montants par mois pour les commandes filtrées.

Analyse de dates (+ Analyse dates)

Entre deux colonnes date (ou Date actuelle comme fin), sur les lignes d'une pile ou d'un calcul source :

  • Moyenne, minimum ou maximum de durée en jours
  • Nombre de lignes dont la durée est dans une plage (ex. entre 3 et 10 jours)

Dans un filtre date « dans la période », le bouton Fin : date actuelle fixe la borne haute à aujourd'hui.

Couleurs par pile et calcul

Chaque pile, calcul, compteur ou analyse peut avoir une couleur définie dans son éditeur :

  • Sidebar — bordure gauche colorée sur l'entrée correspondante.
  • Onglet Valeurs — pastille colorée à côté du nom de la série.
  • Graphiques — couleur de la série synchronisée (modifiable aussi dans le panneau couleurs du graphique).

Si aucune couleur n'est choisie, une couleur par défaut est attribuée automatiquement.

Valeurs et export

Matrice croisée : piles / calculs en lignes, mois en colonnes. Une pastille colorée identifie chaque série (couleur définie dans le filtre, voir Couleurs). Cliquez une cellule pour le détail des lignes.

  • Exporter XLSX — télécharge la matrice visible.
  • Dans le détail d'une cellule : Exporter XLSX pour les lignes filtrées.
  • Colonne PDF — inclure ou exclure une ligne du rapport PDF (mémorisée dans les presets globaux, section valeurs).

Plage d'affichage : totalité, par année, par mois ou plage personnalisée (date début / fin via le sélecteur de date). Par défaut, l'année courante est sélectionnée si elle existe dans les données.

Graphiques

Visualisez les séries visibles dans l'onglet Valeurs (piles avec V/G coché + calculs mensuels).

  • Types : colonnes, lignes, camembert (min. 2 séries).
  • Plage : toutes les dates, année, mois ou plage personnalisée (date début / fin).
  • Couleurs et cases à cocher pour inclure ou exclure chaque série.
  • Cliquez Actualiser le graphique après chaque changement de paramètres.

Piles et calculs filtre courant (colonnes et camembert)

Pour les graphiques en colonnes ou camembert :

  • Inclure les piles filtre courant — séries suffixées « (courant) »
  • Inclure calculs filtre courant — compteurs, calculs et analyses du filtre courant, ventilés par mois

Un avertissement s'affiche sous le sélecteur de plage si celle-ci ne convient pas aux valeurs courantes (aucun mois, colonne date manquante, incohérence avec filtres date du filtre courant).

Texte de légende et valeurs du graphique

Chaque graphique accepte un texte de légende (sous-titre affiché sur le canvas et dans le PDF).

L'interface deux colonnes permet de gérer les valeurs :

  • Colonne gauche — valeurs disponibles ; colonne droite — valeurs actives avec couleur et style
  • Boutons → / ← pour ajouter ou retirer ; Tout retirer pour vider le graphique
  • Par valeur (colonnes) : ligne ou barres ; barres parallèles, empilées (addition) ou empilées (soustraction)
  • Empilement : bouton Colonnes… pour choisir les séries du groupe ; soustraction avec style flèche, demi-colonne ou hachures
  • Case PDF par valeur — inclure la ligne dans le mini-tableau au-dessus du graphique dans le rapport PDF (indépendamment de la case PDF du tableau Valeurs principal)

Dispositions en colonnes

DispositionComportement
ParallèlesBarres côte à côte ; par série, choix Barres ou Ligne (courbe continue sur tous les mois).
Empilées (addition)Les valeurs s'additionnent verticalement par mois.
Empilées (soustraction)La 1re série s'additionne, les suivantes se soustraient visuellement.

Paramètres d'affichage

  • Max ordonnée — fixe l'échelle verticale (vide = automatique).
  • Position légende — droite, gauche, haut (par défaut) ou bas ; les libellés sont affichés en entier (sans troncature).

Édition des valeurs

  • Liste Valeurs du graphique — valeurs actives ; bouton × pour retirer.
  • Menu déroulant Ajouter une valeur — choix parmi les piles/calculs disponibles (V/G).
  • Panneau Couleurs et styles par valeur — couleur et type barres/ligne par série.

Plusieurs graphiques

Bouton + Ajouter un graphique : sous-onglets avec noms éditables (double-clic). Chaque graphique a sa propre plage, type, disposition et séries.

Export PDF Tous les sous-onglets graphiques sont inclus dans le rapport PDF selon l'ordre défini dans Mise en page. Pensez à actualiser les graphiques avant l'export.

Mise en page PDF

Onglet Mise en page : personnalisez le rapport PDF classique (bouton en-tête « Exporter rapport PDF »).

Couleur d'accent

Couleur des en-têtes de tableaux dans le PDF. Presets disponibles ou code hexadécimal. Défaut : #235da9 (bleu).

Blocs du rapport

Liste ordonnée des éléments du PDF :

BlocDescription
Tableau des valeursMatrice Valeurs (période de l'onglet Valeurs, lignes PDF cochées)
GraphiqueUn bloc par onglet graphique (titre, légende, mini-tableau, image)
CommentaireTexte libre inséré dans le rapport
LégendeBloc de note ou légende explicative
Saut de pageForce une nouvelle page à partir de ce point

Utilisez ↑ ↓ pour réordonner et + pour ajouter commentaire, légende, graphique ou saut de page. La configuration est mémorisée par tableau et exportée dans le preset (section layout).

À l'import, choisissez les sections à appliquer (remplacer ou fusionner). Le rapport rapide utilise un preset global : import via section import, puis sections filtres/graphiques/layout.

Presets filtres

Bouton Presets filtres (Filtre courant ou mensuel) :

  • Nommer et enregistrer la configuration actuelle
  • Historique local (30 entrées max) avec date et numéro de version
  • Charger une version antérieure ou mettre à jour un preset existant
  • Exporter fichier JSON depuis la modal

Bouton Importer preset filtre (JSON) : charge un fichier JSON exporté. Inclut piles filtre courant et mensuel, calculs, ordre sidebar, plage Valeurs, mise en page PDF et tous les graphiques.

L'export/import JSON via presse-papiers n'est plus disponible dans les vues filtres : utilisez les fichiers JSON ou le menu ☰ → Presets.

Presets d'import

Dans la fenêtre d'import ou via l'en-tête (voir ci-dessous). La sélection d'un preset dans la liste applique immédiatement la ligne d'en-tête, les colonnes cochées et les formateurs ; les filtres et graphiques du preset sont appliqués à la validation de l'import.

Presets dans le menu

Menu ☰ → Presets :

  • Import — charger un preset global ou par section (JSON).
  • Export — exporter preset global ou une section (import, globalFilter, currentFilter, monthlyFilter, values, layout, charts).

Rapport rapide

Assistant en 4 étapes (menu ☰ → Rapport rapide) pour produire un PDF sans configurer manuellement l'application :

  1. Fichier XLSX — sélectionnez le fichier source (aucun import à cette étape).
  2. Preset global — chargez un JSON preset global ; l'import utilise alors la ligne de titre, les colonnes et formateurs de la section import du preset, puis applique filtres et graphiques.
  3. Période et génération — choisissez la plage de dates pour le PDF (isolée de l'onglet Valeurs), vérifiez le récapitulatif des graphiques, nommez le document et générez.
  4. Impression — le navigateur ouvre la page d'impression (Ctrl+P).
Prérequis Le preset global doit contenir au minimum les sections import et monthlyFilter (ou équivalent). Les lignes Valeurs décochées (colonne PDF) sont reprises depuis la section values du preset.
Le rapport rapide ne modifie pas la plage de dates affichée dans l'onglet Valeurs de l'application : seul le PDF utilise la période choisie dans le wizard.

Rapport PDF

Exporter rapport PDF (en-tête) génère une page d'impression selon l'ordre des blocs défini dans l'onglet Mise en page :

  1. Tableau des valeurs — plage de l'onglet Valeurs, lignes cochées PDF uniquement.
  2. Graphiques — pour chacun : titre, légende, mini-tableau (cases PDF graphique), image.
  3. Commentaires et légendes — blocs texte insérés manuellement.
  4. Sauts de page — entre blocs si configurés.

La couleur d'accent (défaut #235da9) colore les en-têtes de tableaux. Les graphiques sont rendus automatiquement à l'export.

Le rapport détaillé filtre courant (bouton « Générer un détaillé ») est un PDF séparé, centré sur les piles/calculs du filtre courant — voir Filtre courant.

FAQ

Comment activer le filtre global ?

Créez des piles dans l'onglet Filtre global et cochez Actif sur chaque pile à appliquer. Il n'y a pas de case générale : chaque pile s'active individuellement.

Comment personnaliser l'ordre du PDF ?

Onglet Mise en page : réordonnez les blocs (tableau valeurs, graphiques, commentaires, sauts de page) et choisissez la couleur d'accent. Exportez un preset global pour conserver la configuration.

Comment générer un rapport détaillé des filtres courants ?

Onglet Filtre courant → Générer un détaillé. Sélectionnez piles/calculs, colonnes et couleur, puis téléchargez le PDF (page synthèse + détail par élément).

Comment utiliser le rapport rapide ?

Menu ☰ → Rapport rapide. Sélectionnez le XLSX, puis un preset global exporté depuis votre configuration type. La période PDF se choisit à l'étape 3, après l'import automatique.

Le rapport rapide s'ouvre-t-il au démarrage ?

Non : ouvrez-le via le menu burger lorsque vous en avez besoin.

Pourquoi l'onglet Valeurs est vide ?

Vérifiez qu'une colonne date est sélectionnée dans Filtre mensuel et qu'au moins une pile existe. Les dates doivent être correctement formatées à l'import.

Le graphique ne se met pas à jour tout seul

C'est normal : cliquez « Actualiser le graphique » après avoir modifié les paramètres (performance).

Comment partager ma configuration de filtres ?

Dans Filtre courant ou mensuel : exportez un fichier JSON via Presets filtres → « Exporter fichier JSON », ou demandez au destinataire d'utiliser Importer preset filtre (JSON) pour charger votre fichier.

Une pile n'apparaît pas dans Valeurs ou Graphiques

Vérifiez la case V/G dans la sidebar du filtre mensuel. Si elle est décochée, la pile est masquée de la matrice et des graphiques.

Le PDF ne contient qu'un seul graphique

Seuls les sous-onglets créés via « + Ajouter un graphique » sont exportés. Un seul onglet = un seul graphique dans le PDF.

Que fait le bouton Dupliquer (⧉) sur une pile ?

Crée une copie identique de la pile avec « copie » ajouté au nom, utile pour tester des variantes.

Différence entre filtre courant et filtre mensuel ?

Le filtre courant explore les données en direct, avec calculs/compteurs/analyses à valeur unique et export XLSX des lignes filtrées. Le filtre mensuel alimente les comptages par mois, la matrice Valeurs et les graphiques mensuels.

Comment exporter les lignes après un filtre courant ?

Sélectionnez une pile dans Filtre courant : sous les filtres, section « Résultat après filtrage », cliquez Exporter XLSX.

Les piles filtre courant n'apparaissent pas dans mon graphique en lignes

C'est normal : seuls les graphiques colonnes et camembert peuvent inclure les piles courantes. Vérifiez aussi que « Inclure les piles filtre courant » est coché.

Mon preset d'import ne s'applique pas à la sélection

Choisissez le preset dans la liste de la fenêtre d'import : colonnes et formateurs se mettent à jour tout de suite. Les filtres et graphiques du preset sont appliqués après validation de l'import (nouveau tableau ou fusion).

L'export preset filtres ne contient qu'un graphique

L'export JSON inclut désormais tous les sous-onglets graphiques. Réexportez depuis une version à jour de l'application si votre ancien fichier n'en avait qu'un.

Où sont stockés les presets ?

Dans le navigateur (localStorage). Pensez à exporter en JSON pour sauvegarder sur un autre poste.
